Lo que este sitio no hace

Este sitio web no establece cookies, no carga píxeles publicitarios ni de seguimiento, no incrusta mapas, vídeos ni contenido de redes sociales y no incluye formularios ni boletín.

Estadísticas agregadas del sitio

Usamos Cloudflare Web Analytics para ver de forma aproximada el número de visitas y el país. Está pensado para funcionar sin cookies y sin elaborar un perfil de cada visitante. Cloudflare opera también el CDN y el DNS que sirven este sitio.

Tipografías

Las tipografías de la página pueden cargarse desde Google Fonts (fonts.googleapis.com / fonts.gstatic.com). Eso implica una conexión aparte del navegador hacia Google cuando se solicitan esos archivos.
